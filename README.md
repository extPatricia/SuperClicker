# SuperClicker

Un relajante juego clicker ambientado en el océano.

Haz clic para conseguir peces, desbloquea evoluciones, activa multiplicadores temporales y atrapa peces especiales que otorgan grandes recompensas. Mejora tu progreso poco a poco mientras disfrutas de efectos visuales, partículas y animaciones acuáticas. 

Es un juego para Android, pero también puedes jugar desde la web en el siguiente enlace: https://extpatricia.itch.io/aquaclicker
